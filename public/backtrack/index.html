FEATURES // ARCHITECTURE

Built For Streamers & Gamers

01 // OVERLAY HUD

Hotkey-Summoned In-Game HUD

Instantly overlay your clips, gallery, and playback controls over fullscreen games with a single customizable shortcut. Never lose your crosshair or pause mid-match.

02 // ZERO OVERHEAD

Native obs-websocket Architecture

Communicates entirely over native obs-websocket. Never touches your OBS scene collections, encoders, or settings directly—it works on top of whatever setup you already have.

03 // DUAL-PC SUPPORT

Peer-to-Peer Remote Sync & Streaming

Pair dual-PC streaming rigs seamlessly over local area networks or private Tailscale mesh. Stream video preview frames and trigger remote recording buffers without any cloud servers.

04 // STREAM DECK HARDWARE

Two-Way Stream Deck Plugin

Hardware integration with real-time recording stopwatch timers, live replay buffer indicators, and one-tap chapter star bookmark drops directly into your clips.
